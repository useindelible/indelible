Bring your Readwise Reader library, archived articles, and feeds into Indelible.
Import lives under **Settings → Integrations → Readwise Reader**.

## Export from Readwise

From Readwise Reader, export your data. You can bring any combination of:

- **Library CSV**: your saved items and their metadata.
- **Archive ZIP**: the full text of your archived articles.
- **Feeds OPML**: your subscribed RSS feeds.

## Import into Indelible

1. Open **Settings → Integrations → Readwise Reader**.
2. Drop in any of the three files (at least one is required).
3. The import runs in the background; you'll see live counts of imported,
   duplicate, and failed items.
4. Feeds from the OPML file become [feed subscriptions](/docs/how-to/feeds/).

If something looks off, **roll back** the import from the same screen. It moves the
imported items to Trash so you can start over.
