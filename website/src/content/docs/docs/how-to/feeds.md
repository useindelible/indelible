Indelible can follow RSS feeds and surface new items in your Feed. Manage feeds under
**Settings → Feed management**.

## Add a feed

1. Open **Settings → Feed management**.
2. Paste a feed URL and subscribe. Optionally give it a title and a custom poll
   interval.
3. New items appear in your Feed as Indelible polls the source in the background.

Each subscription can **auto-save** new items into a collection, so a feed you always
read end-to-end lands in your library automatically.

## Import an OPML file

Already have feeds in another reader? Export them as OPML and bring them over in one
step:

1. In **Settings → Feed management**, open the OPML import card.
2. Drag in your `.opml` file.
3. Indelible imports each feed and reports how many were created, skipped, or failed.

This is the same mechanism Indelible uses for the feeds in a Readwise export. See
[Import from Readwise](/docs/how-to/readwise-import/).
