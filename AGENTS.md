# AGENTS.md

Conventions for this repository live in [`CLAUDE.md`](CLAUDE.md), which applies to
every coding agent regardless of vendor. Read it first.

Before writing backend code, also read
[`contributing.agents.md`](contributing.agents.md): it defines the architecture
boundaries (module placement, DTO rules, file-size caps) that changes are
reviewed against.

Human contributors should start with [`CONTRIBUTING.md`](CONTRIBUTING.md).
